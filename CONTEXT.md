# Emvex

The company website and the vocabulary used to describe Emvex and its product PIS to visitors.

## Language

**Emvex**:
The company that develops PIS.
_Avoid_: Emvex AB, the company

**PIS**:
Predictive Interruption System, a software product that predicts emotional dysregulation in real time. It is not a hardware device.
_Avoid_: device, hardware, the system

**Emotional dysregulation**:
The state that PIS predicts. Used as a descriptive term, not as a diagnosis.
_Avoid_: diagnosis, condition, disorder

**App**:
The application the user downloads and that PIS is integrated with.
_Avoid_: the platform, the software download
